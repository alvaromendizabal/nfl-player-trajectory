# Research ledger: evidence, rejected interfaces, and remaining work

| Family/interface | Evidence and action |
|---|---|
| Earlier-origin ridge mixture | Worse in the earlier controlled screen. Do not rerun unchanged. Does not rule out neural earlier-origin training. |
| Ridge arrival response | Improved in small training-side folds; some removal ablations support its components. Did not transfer to the tested expanded tree interface. No universal feature-value claim. |
| Turning/braking/orientation additions | Did not earn the declared gate in the tested Round 2 interface. Preserve negative results. |
| Terminal and lagged pair summaries | Round 3 failed. This does not settle learned time/player encoders that retain pair structure. |
| Direct observed-state bundle | First-fold gain failed later-only replication in Round 5. Do not scale or select roles after inspecting the results. |
| Goal-geometry addition | Failed conditional gain in Round 4. Not appended in Round 6. |
| Passing-line state/history | New Round 6 compact coordinate representation: 48 candidates, with separate static/history addition tests and a history-removal comparison. No private NFL result yet. |
| Learned player relationships | Open; requires a separate encoder integration, fixed-capacity control, throughput/recovery tests, and comparison against replayable references. Not exhausted by flat summary failures. |
| Displacement/rate parameterization | Open; must distinguish feature representation from target transformation and preserve the official scoring objective. |
| Training-only sequence pretraining/augmentation | Open in a new justified interface. Prior linear failure is not universal. Do not launch until bounded protocol, throughput, and recovery are proven. |
| Chronological player/role context | Prior evidence exists elsewhere in the project; expand only with fold-local fitting and cold-start/season checks. Do not read future games into features. |
| Additional permitted seasons | Requires fresh rules, event alignment, input-time metadata and provenance verification. Not downloaded or included here. |

No claim is made that the algorithm is irrelevant, that feature engineering alone
explains the gap, or that a leaderboard target is guaranteed. The small diagnostic
sample, representation, supervised exposure, model capacity, and deployment
reproducibility all remain potential contributors. Keeping the estimator fixed
within a feature study makes that study attributable; it does not eliminate other
gaps in the overall system.

Round 6 is another bounded hypothesis, not authorization for an unlimited chain
of tree feature screens. If both arms fail, stop them unchanged. The next decision
should examine a structured temporal representation and recoverable forecasting
pipeline, not just create a larger flat bank. If an arm passes, validate its
incremental contribution and input availability before broader integration.

The historical target supplied for this project remains 0.46340 coordinate RMSE.
Only an appropriately comparable competition evaluation could substantiate
reaching that target. Reused internal fold scores cannot establish a Kaggle rank.
