# Feature research is open — evidence determines the next move

Rounds 1–2: arrival helped the small ridge diagnostic; its origin-mixture,
turning/braking/orientation treatments did not earn retention.
Round 3: arrival and terminal/history relationships failed in the tree interface.
Round 4: direct observed state improved first-fold tree error.
Round 5: that improvement failed later-fold replication.
Round 6: passing-line state and fixed history features failed pooled retention.
Round 7: ordered role/player outcome histories failed later-fold retention.

Do not repeat these treatments unchanged or pool incomparable evaluations.
Negative results are conditional on their tested model, population and interface.
They do not establish feature-space exhaustion.

Round 8 changes the information representation, using a matched learned
pair-sequence encoder rather than another manually pooled tabular feature bank.
It holds architecture fixed within the primary terminal/history comparison.
The prior tree remains an independently replayed numerical reference.

A successful first matched result should lead to unchanged later-date replication,
then explicit own-motion/context ablations and integration into a replayable
forecasting pipeline. Do not expand the ensemble before establishing a stronger,
reproducible representation. A failed result requires inspecting input support,
training behavior and common model quality before changing anything.

Still open: learned player-pair temporal representation stability, focal-history
contribution, role-dependent context, motion/velocity target parameterization,
verified earlier-origin training in a suitable representation, and permitted
season-aligned training expansion. These are hypotheses, not authorized automatic
jobs. All need matched controls and input-time/leakage checks.

The manual rounds are separate local packages and are not on GitHub main. The
new package includes source and aggregate evidence for later reviewed publication;
private tensors, row errors, raw data and model checkpoints must not be pushed.
No 9.9/10 or leaderboard-leading release claim is made while pipeline integration,
independent confirmation and submission parity remain open.
